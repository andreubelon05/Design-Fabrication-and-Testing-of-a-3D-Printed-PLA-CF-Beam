# Design-Fabrication-and-Testing-of-a-3D-Printed-PLA-CF-Beam
For this project the goal was to design and build a 500 mm stepped beam that had to carry 250 N past two obstacles with a safety factor between 1.5 and 2.5. We sized it analytically, checked it with FEA, printed it in carbon-fibre-filled PLA, and loaded it to failure.
